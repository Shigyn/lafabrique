Enfance

Gestion des émotions renard fille/garçon

24,90 €

Il n'est pas toujours facile pour les enfants (et même les adultes) d'exprimer ses émotions.

Grâce à ce tableau, votre enfant pourra décrire ce qu'il ressent sans forcément utiliser de mots.

Le système de scratch permet de placer et retirer les petits "visages". La cordelette permet d'accrocher le tableau.

Le tableau est personnalisable avec le prénom et/ou un petit message sans frais supplémentaires.

L'ajout du message se fait lors de l'ajout de l'article dans le panier.
